추가 회귀 수정: 원자적 JSON 저장이 기본 0600 권한을 만들면서 Linux CI의 권한을 제한한 supervisor가 job.json을 읽지 못했다. 비밀정보 없는 읽기 전용 control 파일만 0644, 폴더 0755로 명시하고 Team 상태는 0600을 유지했다. 실제 Linux ext4의 Docker 작업 수명주기와 권한 회귀로 검증했다. R12는 단순 등록 반복에서 재현되지 않았으나, 후속 실제 마운트 경합에서는 DrvFS/ext4 모두 재현됐다. 재현 및 수정 검사는 scripts/probe_mount_publication.py, Windows 잠금 회귀는 scripts/probe_windows_state_lock.ps1에 남겼다. 기존 실패 기록은 보존했다. 이는 재현된 결함에 대한 수정 완료이며 모든 저장 장애의 부재를 뜻하지 않는다.

검증: 문제별 회귀 테스트 → 전체 테스트 → 새 디렉터리의 실제 Docker managed fixture → 실제 모델의 문서/도식 검토.
필요한 GPU 실행 검사는 기존 훈련 fixture로 수행한다. 고정 결정 fixture와 실제 모델 판단의 증거를 섞지 않는다.
새 Agent 직업 클래스, 연구 간 메모리, 과학적 기준 변경은 이번 수정에 포함하지 않는다.
이번 수정으로 모든 재읽기가 사라졌다는 성능 주장은 하지 않는다. 전체 논문 기반 연구의 호출·시간 개선 비교와 여러 seed의 과학적 검증은 후속 범위다.
