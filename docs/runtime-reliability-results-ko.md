## 실제 모델은 어떻게 검증했는가

일반 Agent와 training 역할 설정을 재사용했다. 중앙 담당자가 Report Reader를 배정했으며, 새 직업 클래스를 만들지 않았다. 입력은 기존 연구 보고서의 검증용 사본, 이미 포함했던 도식, 7,900-byte 텍스트였다. 사본의 표에 ‘optimizer step / epoch: 2,150 / 5’라는 모호함을 의도적으로 다시 넣었다. 원본 보고서는 변경하지 않았다. 텍스트 끝에는 전달 누락 여부를 확인할 marker를 넣었다.

에이전트는 텍스트를 읽고 자기 영수증을 근거로 checklist를 작성해 checkpoint했다. 같은 assignment에서 이어서 보고서 27,862 bytes를 서로 다른 네 구간으로 읽고 PNG를 view_image로 확인했다. 마지막에는 단위가 모호한 표와 ‘이미 표를 고쳤다’는 이력이 충돌한다고 지적하고 정상 제출했다. 답과 verdict는 미리 정하지 않았다.

모델 응답은 8회, 도구 오류는 0회였다. 7,900-byte 본문이 바로 다음 모델 입력에 그대로 들어간 것도 원본 프롬프트로 대조했다. 이 실행을 재열어도 응답 수는 8회로 유지됐다. 이는 기존 인터페이스를 확인하는 통제된 검증이며 새로운 과학적 연구 결과가 아니다. 이전의 24회·6회·7회 문서 검토와 입력·지시문이 같지 않으므로 이를 효율 개선율로 계산하지 않았다.

## 테스트와 실제 실행의 구분

- 전체 회귀: **156 passed, 3 skipped**. 생략된 항목을 수행했다고 세지 않았다.
- 실제 Windows/WSL: Windows 읽기 잠금이 잡힌 파일의 교체 쓰기를 시도해 실제 OS 오류와 복구를 확인했다. 오류를 Python에서 강제로 발생시킨 검사가 아니다. 다만 이것이 과거 Get-Content 사건의 원인이었다고 단정하지 않는다.
- 실제 Docker managed fixture: 실패한 보호 측정 → 동일 업무의 수정 → 별도 역할 검토 → 완료 → 재열기 추가 호출 0을 확인했다. 판단은 고정된 시나리오다.
- 실제 GPU fixture: RTX 3080 Laptop GPU에서 학습, 약 38.9MB 체크포인트 저장, epoch 경계 재개, 연속 학습과의 가중치 완전 일치, 유지관리자 추론 코드의 독립 평가를 확인했다. 판단과 리뷰는 고정 시나리오이며 자율적인 모델 선택 증거로 세지 않았다.
- 실제 공개 자료 도구: Crossref/GitHub 응답, JMLR PDF 30쪽 텍스트 추출, 고정 커밋의 Python 본문 다운로드가 통과했다. 모델 호출 없는 도구 준비 검사다.
- 실제 모델: 위의 문서·도식 읽기와 지적·제출은 설정된 provider를 사용한 실제 호출이다. 중앙 배정 및 checkpoint 재개 검증 절차는 고정했다.

## 유지한 경계와 남은 범위

상태·이벤트의 권위 있는 기록은 계속 Team이 담당한다. 읽기 범위와 checklist는 현재 작업 안의 기록이며, 과거 연구를 자동 검색하는 기능이 아니다. 독립 검토자는 다른 검토자의 결론을 받지 않는다. 입력과 평가 정답 분리, 보호된 평가기, shell 권한과 불확실한 실행의 수동 재시도 규칙을 완화하지 않았다.

이번 수정은 관측된 결함의 재발 방지와 관련 인터페이스 검증이다. 모든 상황에서 반복 읽기가 사라졌거나 전체 연구 시간이 줄었다는 주장은 하지 않는다. 출처 영수증 대조를 앞당긴 효과도 전체 논문 기반 연구를 다시 실행해 정량 비교한 것은 아니다. 실제 의미 검토는 여전히 필요하고, checklist에 passed라고 적었다고 과학적 사실이 검증되는 것은 아니다.

새 코드에서는 새 run 디렉터리를 사용해야 한다. 과거 실행의 contract를 자동 변경하거나 마이그레이션하지 않았다. 일시적 교체 오류의 재시도가 끝나도 저장소가 계속 사용할 수 없으면 운영자 복구가 필요하다. 같은 작업 재개는 저장된 상태로 ‘모델 호출 전이며 미실행’임을 확인한 경계에만 적용한다.

원본 실행은 repo의 `tmp/reliability-*`에, 열람용 결과와 실제 모델 trace는 세션의 `reports/runtime-reliability-20261031/`에 보존한다. 과거 연구 경험 축적과 목표 전환 과제는 TODO의 E/G 항목에서 이어갈 예정이다.
